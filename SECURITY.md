# Security Policy

## Melaporkan Kerentanan

Jika Anda menemukan kerentanan keamanan pada SekolahApp, **jangan** membuka issue publik.

Silakan laporkan melalui:

- Email: security@sekolahkit.id
- Atau gunakan [GitHub Security Advisories](https://github.com/sekolahkit/sekolah-app/security/advisories/new)

## Yang Harus Dilaporkan

- Kebocoran data atau akses tidak sah
- Bypass autentikasi atau otorisasi
- SQL injection atau XSS
- Eksposur secret/credential
- Kerentanan pada dependency

## Response Time

- Konfirmasi penerimaan: 48 jam
- Penilaian awal: 7 hari
- Patch release: tergantung severity

## Responsible Disclosure

Kami meminta Anda untuk:
1. Tidak mengeksploitasi kerentanan di luar kebutuhan verifikasi
2. Tidak membagikan detail kerentanan sebelum patch dirilis
3. Memberikan waktu yang wajar untuk perbaikan

Terima kasih telah membantu menjaga keamanan SekolahApp.
